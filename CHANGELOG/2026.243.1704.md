# 2026.243.1704 — feat(desktop-bed): the shell IPC steps assert through the quickshell verb

## Summary

The desktop bed drove omarchy's Quickshell shell through `command:` steps running
`env OMARCHY_PATH=… omarchy-shell …`. That is exactly the shape `plugin-quickshell` exists to
replace: `qs ipc` reports IPC-level failures — "Target not found.", "Function not found.",
argument-count errors — on **stdout while exiting zero**, so a `command:` step asserting "the
menu opened" passes when the shell rejected the call outright.

**18 of the 21 shell-IPC steps now use the typed verb.** The three that remain `command:` steps
are documented in place; `omarchy-menu summon apps` is a CLI that resolves the apps list before
calling the shell, so running the program IS the assertion.

### Two failure-open holes closed, not one

Converting to the verb closed the qs-level hole. Running it exposed a second one *inside* it, and
the first bed run failed **22** checks:

```
quickshell: shell.summon: Too few arguments provided (2 required but 1 were provided.)
```

Eight of ten `summon` steps passed one argument. The signature was read from the guest's own QML
rather than guessed:

```
/usr/share/omarchy/shell/shell.qml:1002  function summon(id: string, payloadJson: string): string
```

Every argument a QML function declares is required, so a panel with no payload of its own still
passes `'{}'`. The other 14 failures were the mapped/OCR assertions cascading behind panels that
never opened.

**The second hole is the shell's own contract, and the verb cannot close it.** Measured on the
live guest:

```
$ qs ipc -n -p /usr/share/omarchy/shell call -- shell summon totally.bogus.plugin '{}'
unknown
exit=0
$ qs ipc -n -p /usr/share/omarchy/shell call -- shell summon omarchy.weather '{}'
ok
exit=0
```

`summon` answers `"ok"` or `"unknown"` and exits zero either way, so exit status proves only that
the round-trip happened — **not that anything opened**. All ten summon steps had no `stdout:`
assertion and would have passed against a shell that summoned nothing. Each now asserts
`^ok\s*$`, with the reason recorded once at the first of them rather than repeated ten times.
