# 2026.245.1957 — feat(vm): auto-login on every omarchy check VM (unattended desktop for evals)

## Summary of changes

Compose the **`omarchy-autologin`** candy (sddm autologin drop-in + sddm restart → uid-1000 account, `hyprland-uwsm.desktop` session) onto the check VMs that assert runtime/desktop behavior, so no evaluation stalls at the greeter and screenshots/recordings show the logged-in session:

- `check-omarchy-hybrid-gpu-vm` — the L3 harness now also lands on a real session
- `check-omarchy-pr-vm` — the VM PR-injection lane
- `check-charly-omarchy-vm` — the toolchain-deploy proof (keeps its `on_finalize: golden` snapshot)

(Already composed: `check-omarchy-desktop-vm`, `check-omarchy-pr-vm-visual`.)

**Disk encryption** is disabled on every omarchy check VM: the `omarchy-vm` template declares `encrypt: false` (single source; documented reason — no LUKS passphrase on the seed, install stays unattended) and the pacstrap-VM source has no encryption field; every check VM derives from one of those.

**Deliberately NOT added (documented exception):** `check-omarchy-iso-vm` and `check-omarchy-pacstrap-vm` — their sole claim is a STOCK unattended install (ISO / from-packages) is correct; autologin would change exactly what they gate (rationale in the candy + bed comments).
