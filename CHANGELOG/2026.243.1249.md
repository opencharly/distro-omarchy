## One assertion removed, with its root cause

The bar-reveal assertion is gone. It is not a scope reduction - it is a race in omarchy's
shell, measured across four runs of this bed.

Bar visibility is driven by a file watcher, not an event, in the shell bar plugin QML. A
Process probes for the bar-off flag, and a FileView on the toggles directory re-runs that probe
whenever the directory changes.

CREATION of the flag (hide) fires the watcher every time - the bar parks off-screen within a
second, which is why the two assertions around hiding are reliable. REMOVAL (reveal) does not.
Twice the bar was still at y=-26 after 29s of polling while omarchy-toggle-bar off had exited
0, and returned on screen much later in the same run, when unrelated activity happened to touch
that directory again.

So the delay is not a duration to size an eventually against - it is until something else
changes that directory. A longer timeout would be a blind wait on another project's race, and
an assertion that passes or fails on unrelated activity is worse than no assertion: it teaches
a reader to ignore a red bed. The behaviour hypr-layers exists to prove - that hiding PARKS the
surface off-screen instead of unmapping it - stays fully covered by the two deterministic
assertions, and the evidence is recorded in the bed for whoever files it upstream.
